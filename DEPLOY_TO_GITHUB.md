# Deploy this portfolio to GitHub Pages

This folder is ready to publish as a static GitHub Pages website.

## Recommended repository
Create a public repository such as:

`ai-video-portfolio`

## Upload
Upload the CONTENTS of this folder to the repository root.
`index.html` must be at the top level of the repository.

## Enable GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages** under **Code, planning, and automation**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Choose the `main` branch.
6. Choose `/(root)`.
7. Click **Save**.

GitHub will then publish the site at a URL similar to:

`https://YOUR-USERNAME.github.io/ai-video-portfolio/`
